## 1. 项目概述

### 1.1 背景

小学数学教师/家长手上有大量**试卷与练习册照片**（手机拍摄、扫描件），希望：

1. 把照片里的题目**收进题库**（结构化、可检索、可管理）；
2. 校对识别错误（拍照识别必然有错）；
3. 从题库里**挑题组成新卷**并打印给学生做；
4. 把已经写满/丢失的原卷**按原版面重新打印**一版干净的。

项目最初的识别由「对话内的 agent 看图完成」，每次识别都消耗对话 token 额度且无法在产品内闭环。本项目的目标是把整条链路产品化：**上传即识别、自动入库、在线校对、在线组卷、一键打印**。

### 1.2 产品定位

一个**多人在线题库 Web 应用**（`app/`，发布于 WorkBuddy 云服务），外加一条**本地 Python 生产线**（`engine/` + `tools/`）用于离线校对页生成与成卷。两条链路共用同一套识别规范（schema v2）与资源处理规则。

- 线上地址：<https://shijuan-question-bank.app.workbuddy.host/>
- 账号体系：应用自己的账号（手机验证码 + 微信扫码），**开通制**——只有管理员开通过的账号才能使用题库。
- 计费：云数据库/存储/认证不计积分；上传即识别调用免密钥大模型，按 token 计积分（实测约 0.11~0.21 分/页）。

### 1.3 目标（Goals）

- G1：上传照片 → 自动整页全量识别 → 结构化入库，全程无需人工触发识别。
- G2：识别结果可校对、可手工修正（含题干、选项、题型、插图）。
- G3：支持从题库挑题组卷，并在卷面上就地排版（拖拽、列数、编号方案）。
- G4：支持按原卷版面还原打印与按题型重排合卷，输出可打印的 A4 卷面 / PDF。
- G5：识别不确定性对用户透明（`[?]`、低置信度、可疑题标记），并提供重扫的安全网（自动备份 + 一键恢复）。
- G6：多用户数据互相隔离，未开通账号零数据可见。

### 1.4 非目标（Non-Goals，明确不做）

- **不做答案、解析、对错判定、学生作答转写、批改、知识点/难度标签**——schema v2 收窄为「识别 + 题型分类」。
- 不做错题本/重做记录（v1 已移除的字段不恢复）。
- 不做微信小程序（2026-10-05 做过一版，按要求删除；如重做需重新立项）。
- 不做批量后台识别队列、不做邮件/消息通知。
- 识别层**不去重**（去重只发生在成卷层，见 FR-808）。

### 1.5 术语表

| 术语 | 含义 |
|---|---|
| 整页全量识别 | 把一页上的所有印刷题目全部识别入库，不筛选、不跳题 |
| schema v2 | 题目 JSON 结构版本（只有题干/选项/图形/题型/来源/置信度） |
| `[?]` | 模型标记的「看不清」占位，必须配低置信度 |
| 题区框 `source.bbox` | 题目在原图上的像素坐标 `[左,上,右,下]`，用于裁剪对照 |
| 插图子图 | 题内插图单独裁剪/记录的图形片段（stem 中 `t:"figure"`） |
| 板块（section） | 卷面印刷的大题标题，如「一、算一算」 |
| 题型桶 | 卷面排版用的 9 个分类（选择/填空/比大小/计算/判断/应用/几何/证明/其他） |
| 照片卷 / 自建卷 | 上传照片得到的卷 / 从题库挑题组成的卷 |
| 按卷还原 | 照某份卷的原版面重排一版干净卷面（`--by-doc` / `print.html?id=`） |
| 合卷 | 全库题目按题型合并重排成一张练习卷（`paper-all`） |
| 吸附 | 本地用图像算法把模型给的粗框修正到真实墨迹边界 |
| 外扩兜底 | 吸附失败时按比例放大模型框的保底策略 |
| 开通制 | 账号需管理员批准（`app_access.status=approved`）才能使用 |

## 4. 数据需求

### 4.1 题目结构（schema v2，唯一正本 `prompts/recognition-spec.md`）

```json
{
  "schema_version": 2,
  "id": "q-20260930-001",
  "no": 1,
  "section": "一、算一算",
  "type": "calculate",
  "stem": [
    {"t": "text",  "v": "三位数□24×4 的积是三位数，□里最大能填（　　）。"},
    {"t": "latex", "v": "70\\times4="},
    {"t": "figure", "state": "crop", "src": "q-...-fig1.jpg",
     "bbox": [978, 711, 1335, 963], "caption": "图：泳道示意图，泳道长 50 米",
     "confidence": 0.95}
  ],
  "options": [],
  "source": {"file": "2026-09-30-小学练习页.jpg", "page": 1,
             "bbox": [185, 245, 520, 310], "crop": "q-20260930-001.jpg",
             "printed_no": "（1）", "crop_reviewed": true, "review_note": "…",
             "paper": "2026-10-01-第2单元练习卷.jpg", "paper_title": "…", "paper_page": 2,
             "qtype_manual": "calc", "edited": true},
  "confidence": {"stem": 0.97, "options": null, "figure": null},
  "created_at": "2026-09-30T23:10:00+08:00",
  "updated_at": "2026-10-05T16:49:14+08:00"
}
```

字段约束：
- `type` 仅 6 值：`choice/fill/calculate/solve/geometry/proof/other`（schema 层唯一「分析」字段）。
- `stem` 片段三型：`text` / `latex` / `figure`；题内多行用 `\n`；片段是混排单位不是行单位。
- 填空方框/圆圈/三角/星照实转写 `□○△☆■●▲★`；下划线留空 `____`；圆括号留空 `（　　）`。
- `figure.src` 必须指向该插图自己的子图，**绝不能**指向整题裁剪图。
- `source.printed_no` 记该题自己的印刷题号；续行为空串。
- 多张照片同卷才写 `source.paper/paper_title/paper_page`。
- **升级 schema 的唯一途径**：改规范 → 升版本 → 同步 `db.py`/`render.py` → 写迁移脚本（先备份、可回滚）。

### 4.2 云端数据库（6 张表，全部 `owner_id TEXT DEFAULT auth.uid()` + RLS）

| 表 | 关键列 | 说明 |
|---|---|---|
| `papers` | title, paper_date, subject, grade, status(pending/processing/done/failed), status_note, page_count, question_count | 一份卷 |
| `paper_files` | paper_id, page_no, filename, storage_path, **width, height**, size_bytes | 每张原图 + 像素尺寸（网页抠图必需） |
| `questions` | paper_id, seq, qno, printed_no, section, qtype, stem(jsonb), options(jsonb), source(jsonb), confidence(jsonb) | 识别出的题 |
| `app_access` | user_id, status(pending/approved/blocked), role(user/admin), phone, name, note | 使用权限 |
| `custom_papers` | title, **question_ids**（有序引用）, **layout**(jsonb) | 组卷 |
| `question_backups` | paper_id, reason, q_count, payload(整卷快照), created_at | 重扫前备份，每卷留 5 份 |

配套数据库函数（SECURITY DEFINER）：`app_can_use()`、`app_is_admin()`、`app_admin_users()`、`app_admin_set_status(user_id, status)`。前两个被 RLS 引用，必须 SECURITY DEFINER 避免递归。

### 4.3 本地存储

- `data/questions/*.json`（135 题，schema v2）、`data/crops/`（题区 + 插图子图）、`data/thumbs/`（520px 缩略图）、`data/benchmark/`（原图）、`data/render/`（网页根：校对页 + 可打印卷面）、`data/paper/`（版面体检 manifest + 每页 PNG）、`data/cuotiji.db`（SQLite）。
- SQLite `questions` 表：id/no/type/stem_text/payload/created_at/updated_at（WAL）。

### 4.4 排版数据（`custom_papers.layout`）

```
layout = {
  sections: [{title（纯名）, type（桶键）, cols, smallNo?, ids:[题目id…]}],   // 顺序=卷面顺序
  numbering: {big:{show,style,pre,suf}, small:{…}},   // 大题/小题序号方案
  types: {题目id: 桶键},      // 本卷题型覆盖
  figs:  {题目id: mm},        // 本卷插图宽度覆盖
  caps:  {题目id: [图序号…]}   // 本卷被移除的图下说明
}
```

## 5. 识别质量需求（量化指标）

> 依据：README「自动识别」章 + `tools/reco_rows_compare.py` / `figsnap_eval.py` / `reco_audit_check.mjs` 实测。

| 指标 | 目标值 | 实测值（deepseek-v4.1-flash） |
|---|---|---|
| 题干/选项转写 | 字符级一致 | 相似度 0.955~1.000 |
| 切题数量、印刷题号、题型、板块 | 全对 | 24/24、另次 4/4 |
| 单页识别耗时 | ≤10s | 5~10s/页 |
| 单页识别成本 | ≤0.25 credits | 0.11~0.21 credits/页（全库 11 页 ≈2 分） |
| 题区框覆盖率（应用题页） | ≥0.95 | 吸附后两次实测 1.000 / 0.604（外扩策略 0.747，密集页 16/24 完全覆盖） |
| 插图框平均 IoU | ≥0.75 | 吸附后 0.817（外扩 25% 仅 0.564）；低于 0.5 的张数 5→0；变差 0 张 |
| 识别后自检误报率 | ≤5% | 3%（4/135，逐条核过全是真问题） |
| 自检漏报 | 已知边界 | 「漏字/认错数字/认错人名」形式合法，机器判不出——不掉换模型，靠备份+重扫兜底 |

**质量设计原则**：
1. 宁可留 `[?]` 交人工，不可编造（被篡改的题比缺失的危害更大）。
2. 自检判据**只减不增**（误报多了人会忽略红色）。
3. 坐标「宽松框 + 明确标注」优先于「假精确」；缩略图偏了靠点进整页原图兜住。
4. 已有卷的坐标更新走**离线重算 + 按 seq 写回**，不用「重新识别」（它会重掷文字、换片段切分、花额度）。

## 7. 约束与外部依赖

1. **云存储只有只读列举接口**：智能体拿不到用户照片、也不能往云存储写裁剪图 → 裁剪图一律不落盘，网页按 bbox 用纯 CSS 从原图实时抠 → `paper_files` 必须存原图像素宽高。
2. **免密钥 LLM 按精确 Origin 校验**：识别只能在应用自己的页面里跑；`curl` 调不通；改域名/换 applicationId 会使云登录 Origin 校验失败。
3. **发布必须复用 applicationId** `wbapp_xotiBVMY1FXqdzhi2ZChQ7`（domainPrefix `shijuan-question-bank`）。
4. **微信登录只能 PC 扫码**（无第二屏幕可扫）；手机上真正一键登录需改小程序（已评估过，不做）。
5. **建表与 GRANT 是两道门**，漏 GRANT 会得到形似策略失效的 `42501`。
6. **`questions.id` 是 GENERATED ALWAYS**：不接受显式插 id → 恢复/替换必须原地 UPDATE。
7. **云端无按 jsonb 条件删除**：删题只能先筛 id 再逐条删。
8. 模型输出有**随机性**（同图两次调用，错的题不重合；y 坐标差 10~250px）——这是产品形态（备份/重扫/自检）的根本原因。
9. 写库路径（建卷→上传→addQuestions→状态流转）**没有被自动化端到端验证过**（RLS 要求本人登录态，脚本代不了）——上线后首次真实上传即首测。

## 9. 风险登记

| 风险 | 影响 | 对策（已实现） |
|---|---|---|
| 模型坐标随机波动 | 缩略图偏、框串行 | 本地吸附（refine.js）+ 外扩兜底 + 「自动定位」标注 + 点看整页原图 |
