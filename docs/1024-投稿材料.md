## 二、作品介绍（直接粘贴，1222 字 / 上限 2000）

```
【谁会用它】
小学数学老师、家教和家长。手里一堆写完的练习卷，想"重打一份干净的空卷"给学生再做；或者想把几十份卷子攒成能检索、能重组的题库——过去只能一个字一个字敲进 Word。

【怎么体验】
打开链接 → 手机号验证码登录（电脑上可用微信扫码）→ 首页点「载入示例卷」，直接拿到 5 份真实试卷、135 道题的完整效果：照片、识别结果、单题对照、卷面排版、打印，全都能点。
想自己试：点「上传新试卷」，一次选多张照片（选择顺序＝页序），上传完成自动开始识别，5—10 秒一页，识别完直接进卷详情。

【四步闭环】
① 整页全量识别：拍照 → 结构化题库。题干、选项、题内插图、题型、板块、印刷题号、在整页原图上的坐标、每处置信度。印刷小字、竖式、方格、□○△☆ 占位符号按原样保留，公式走 KaTeX 排版，不是把照片贴上去。
② 逐题校对：左边是按坐标从原图里抠出来的那一块，右边是结构化还原，左右对照着看。认错了可以当场就地改——算式有公式编辑器，插图可以从原图重新切、能摆正、能改显示大小与位置。
③ 识别后自检：机器判得出来的硬伤自动标红——看不清的 [?]、算式形式异常（如 12-+）、题号跳号、题干重复、空题干、选项不足 2 个、低置信度。只让你复核这几道，实测误报率 3%。
④ 组卷与打印：从题库里点「加入」挑题，右栏卷面本身就是编辑画布——拖题换位置、改板块标题、切 1/2/3/4 列、编号样式（中文/阿拉伯/字母 × 顿号/括号/方头括号）当场生效，题型自动分板块（选择、填空、比大小、计算、判断、应用、几何、证明）。打印是自算的 A4 真分页，不会从题目中间劈开；照片卷还能「按原卷版面」逐卷还原成一份干净卷面，页边距可调，直接打印或存 PDF。

【能得到什么结果】
一份写满的旧卷，十分钟内变成：可检索的题库 + 一份干净可打印的新卷面 + 一份随时能重组的组卷。老师省掉的是"手打"这道最枯燥的工序。

【几个不糊弄的地方】
· 坐标不假装精确：模型对绝对位置感知很弱，同图两次调用的 y 能差 10—100px。所以界面明写「自动定位」，靠"点进去看整页原图"兜住，并用行/列投影做图形块吸附（9 张人工核过的插图框，平均 IoU 从 0.56 提到 0.82）。
· "重新识别"等于重掷骰子：会把现在对的题也换掉。所以重扫前自动备份整卷，能一键回滚；恢复按序号原地更新，不删重建——否则自建卷里引用过的题会全部失联。
· 只做识别与题型：不猜答案、不判对错、不转写学生笔迹。编出来的答案比没有答案更害人。

技术上：网页应用 + 云数据库/云存储/账号体系（多用户各自独立题库，使用权限按账号开通），识别走云服务的免密钥大模型通道，不需要申请任何 API key；KaTeX、字体、SDK 全部内联，不依赖任何外部 CDN。词库、组卷、排版、打印四套引擎的规则分别收敛在单一文件里，改了不会两处打架。
```

## 五、上墙前必做（按优先级）

### 1. ⛔ 访客体验门槛（最大风险，建议今天就改）
现在的流程是：点开链接 → 登录卡 → 手机验证码/微信扫码 → 新账号自动登记为 `pending` → **管理员开通后才能看到任何数据**。
评委点开只会看到登录页，评"完成度/使用体验"时基本拿不到分。

两个解法（选一个，推荐 A）：
- **A. 加只读演示入口**：`?demo=1`（或路径 `/demo.html`）在线上也启用 `local-demo.js` 那套内存题库，落地页按钮写明「🚀 免登录看效果」。改动集中在 `local-demo.js` 的 hostname 判定 + 首页一个入口 + `?v=` 重新发布；不动数据库、不影响真实用户。
- **B. 给评审专用账号**：在介绍里写「评审体验账号：手机号 xxx / 验证码任意」——需要改登录逻辑，且暴露一个免验证入口，风险比 A 大。

> 顺带一个便宜的补丁：解析 `?demo=1` 时把顶栏的"管理员/退出"换成一个「这是演示数据」的角标，避免评委以为进了别人的账号。

### 2. 首页首屏加一句引导
现在首屏是"我的试卷 + 上传新试卷"，新用户不知道该点哪。加一条：**「第一次来？点这里载入示例卷（5 份卷 / 135 题，不用上传）」**。

### 3. 手机端
微信登录只支持**电脑扫码**（走的是网站应用 `snsapi_login`，必然是一张二维码），手机上只能手机号验证码。介绍里已经写了，但如果评委用手机打开，要保证验证码链路是通的（这条还没在真机上端到端验过）。

### 4. 创作对话记录链接
细则要求用来核验"确实是用 WorkBuddy 做的"。建议选本项目的主对话，分享前确认：① 评委能打开；② 不含你的手机号、云服务密钥、他人信息。必要时先在对话里问一句"整理一下这个项目的架构"，用那段干净的对话去分享。

### 5. 发布前确认
如果为了第 1 条改了 `app/js/*.js` 或 `app/css/*.css`：全站 `?v=` 要 bump，重新发布**必须复用同一个 `applicationId`**（`wbapp_xotiBVMY1FXqdzhi2ZChQ7`），换域会让云登录的 Origin 精确校验失败。改完跑一遍 `node tools/app_pages_check.mjs --port 64911`。
