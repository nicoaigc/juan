**关键架构决策**：

1. **识别在前端跑，不在后端**：免密钥 LLM 通道按精确 Origin 校验，且规范禁止手写 `/.cloud/llm` 请求——只能走 SDK、在应用自己的页面里调。所以「上传即识别」天然是前端职责，后端没有可用调用点。
2. **裁剪图不落盘**：云存储只有只读列举接口，智能体既拿不到用户照片也不能写文件。网页用纯 CSS 按 `source.bbox` 从原图实时抠图（`Render.cropBox`），因此 `paper_files` 必须存原图像素宽高。
3. **两条输出链路口径统一**：校对页（给人核对）与卷面（给学生做）共用同一套资源处理（KaTeX 内联、图片 data: URI、符号内联 SVG、`mathify`），**不各写一套**。
4. **分型分治**：`sheet.js` 只管画、`sheet-edit.js` 只管交互、数据存哪由页面定；`render.py`/`render.js` 是同一渲染规则的 Python/JS 两份实现，靠 `fig_view_check.py` 等对账脚本钉一致。

## 4. 数据模型

### 4.1 schema v2（题目 JSON）

字段与约束见《需求文档》4.1。技术要点：

- `stem` 是**片段数组**（text/latex/figure），按阅读顺序；题内多行用 `\n` 表示（渲染层换 `<br>`）；**片段是「文字/公式/图形」的混排单位，不是行单位**。
- 识别层**不去重**：同一份卷拍成多张有重叠照片时，接缝处的题会入库两次——照实记录；去重只发生在成卷层（同板块内按内容指纹）。
- 切题粒度：**印刷小题号出现几次就成几题**；无题号板块（口算/竖式/递等式/比大小）以「每个能独立作答的算式」为切分单位；续行 `printed_no` 为空串。
- 升级路径：改规范 → 升 `schema_version` → 同步 `db.py`/`render.py` → 写迁移脚本（`tools/migrate_v1_to_v2.py` 为模板：先备份、再转换、可回滚）。

### 4.2 云端数据库

6 张表 + RLS + 4 个函数，详见需求文档 4.2。工程细节：

- 三张业务表（papers/questions/paper_files）策略 = `owner_id = auth.uid() AND app_can_use()`；`app_access` 的 INSERT 策略 = `WITH CHECK (user_id=auth.uid() AND role='user' AND status='pending')`——客户端只能给自己登记待开通。
- `app_can_use()` / `app_is_admin()` 必须 **SECURITY DEFINER**（否则在 `app_access` 自己的策略里递归）。
- 建表和 GRANT 是两道独立的门，漏 GRANT 报 `42501`（形似策略失效）。
- `questions.seq` 是全卷顺序依据（列表/打印/组卷都按它排）；`qno` 是模型给的页内序号（自检「题号不连续」判据用）。
- `custom_papers.question_ids` 是有序引用数组（不复制题目）；`layout` 结构见需求文档 4.4。
- 回滚 SQL（管理员被锁在门外时）见 README「使用权限」节。

### 4.3 本地 SQLite

`data/cuotiji.db`，WAL 模式，单表 `questions(id, no, type, stem_text, payload, created_at, updated_at)`；`import` 是 upsert（只增改不删），修过数据后必须 `--prune` 清孤儿。

## 5. 核心模块设计

### 5.1 自动识别管线（`app/js/recognize.js`）

```
选照片(File[]) ──▶ loadImage ──▶ buildRulerCanvas ──▶ toDataURL(jpeg 0.86)
                                                            │
                                        cloud.llm.chat.completions.create（stream）
                                                            │
                                        parseJson（剥 ```json 围栏、取首尾大括号）
                                                            │
                        ┌───────────────────────────────────┼──────────────────────────────┐
                        ▼                                      ▼                              ▼
               Refine.snap（题区吸附）              Refine.snapFigures（插图吸附）      失败/不存在
                        │                                      │                              │
                        ▼                                      ▼                              ▼
                   q._rb（题区框）                     f._sb（插图框）                 （不挂标记）
                        └──────────────┬───────────────────────┘
                                       ▼
                          toRow 归一化（写 questions 行）
                                       ▼
                          auditOne/auditPaper（识别后自检）
```

**刻度图（buildRulerCanvas）**：给原图加「参考网格 + 边缘刻度」——网格 100px、数字 500px、白边 80px（PAD）、长边缩到 ≤1600（MAX_EDGE，scale=min(1,1600/max(W,H))）。**刻度数字标的就是原图坐标**（网格按原图 100 的倍数画），模型照读出的坐标无需换算；实测把误差从 230~390px 压到 30~60px。Python 等价版 `tools/make_ruler_image.py`。

**模型调用（callModel）**：`stream:true` + `stream_options:{include_usage:true}` + `response_format:{type:"json_object"}`。**双门槛超时**：绝对 20 分钟 + 空闲 10 分钟（收到新内容重置空闲计时）——旧的 240s 总上限会误杀慢模型（space-bunny 题多页 160s+ 常见）。

**归一化（toRow）**：
- 板块名 `normSection`：trim + 去尾部句号（模型爱给「一、算一算。」补句号，不归一化同一板块会被当两个）。
- 选项 `stripOptPrefix`：去 `A.` 前缀（字母是版式元数据，渲染层统一生成；不去会印成「A. A. 42」）。
- 题区框：优先 `q._rb`（吸附），否则 `widen(模型框, clamp(框高×0.35, 40, 110))`。
- 插图框：优先 `f._sb`，否则 `widen(模型框, clamp(min(宽,高)×0.25, 30, 80))`。
- `qtype` 白名单 6 值 + `other` 兜底；`printed_no` 强制字符串；`source={file,page,bbox}`。

**整卷识别（recognizePaper）**：`replace=true` 先 `deleteQuestions`；逐页 try/catch（单页失败不影响其他页）；结束写 `status(done/failed)` + `status_note`（失败明细）。

**单页重扫（rescanPage）**（多页卷）：① 先识别（**失败则数据一个字节不动**）→ ② 用改动前抓到的 id 删该页旧题 → ③ 插新题（临时大 seq）→ ④ 该页 seq 段**原地替换**并 `setQuestionSeqs` 重排全卷。两条铁律：删题必须用改动前抓到的 id（先插后删，按页重查会把新题一起删掉）；`pageRowsOf` 先按 `source.file` 精确匹配、匹配不到才退回 `source.page`（老数据页号可能重复）。

**识别后自检（auditOne/auditPaper）**：形式判据（`[?]`、算子连用/尾随/首字符乘除、括号不配对、题号非严格 +1、题干完全重复、空题干、选项<2、置信度<0.7）。设计原则**只减不增**；`=` 结尾是正常作答位不算可疑；实测误报率 3%。页面用法：卷详情汇总条 + `.qrow.sus` 红条 +「只看可疑 N 题」；`Render.hasDoubt` 优先读页面注入的 `_flags`。

### 5.2 坐标吸附（`app/js/refine.js`，v5.3，Python 孪生 `tools/refine_proto.py`）

**为什么需要**：模型文字转写逐字准，但绝对坐标「按版式均匀铺开」（同图两次调用 y 差 10~250px）。三条朴素修法实测排除：全页统一行带（手写笔迹连成 706px 大块）、模型框中心外扩（中心本身偏到相邻行）、外扩到必不漏（密集页要 ±250px，框宽到页面 47%）。

**题区吸附（Refine.snap）——「结构判据 + 单调对齐」**：
1. 大图缩到工作分辨率（workMax=1600，参数 `PX_KEYS` 按比例同步缩放）；
2. **印刷黑掩膜**：`lum<118 且 chroma<42`（红笔/铅笔/阴影被排除）；亮度阈值自适应 `min(118, 0.68×纸面75分位)`（暗照片会把纸面算成墨，行投影整页失效）；
3. 行投影 → 行带（peakMin/peakRel/peakDist/smoothW/mergeOv）；
4. 版面横向结构分类：单段→软/硬题目带（wide 0.40 / hardWide 0.55），多段看空洞率（holeFrac 0.35），段起点 ≤20% 页宽判为板块标题；
5. 模型行按上下顺序**单调对齐**（DP，允许跳过板块标题、硬题目带必须被覆盖；stretchPen 反「拉伸吞行」）；
6. x 吸附列投影边界、y 向有墨处生长（growGap/growHRatio/growExt）。
7. **兜底**：任何一步抛错或 DP 不可行 → 返回 null → 调用方退回「外扩 35%」，绝不比老策略差。

**插图吸附（Refine.snapFigures）——另一套判据**：插图的错法是「边界」不是「顺序对应」（框偏/太小/伸进旁边内容），不能复用题区那套（hmin/hmax 是文字行高度，插图块 150~300px 第一关就被滤掉）。做法：ROI 内行/列投影分段（允许块内 ≤gap 空白）→ 选与**模型框区间重叠最大**的段（不能只看中心——q35 中心整个落在空白里）→ 行列交替收敛 → 每边限制外移幅度 → 外缘补余量。**逐张独立兜底**：失败/面积超 2.4 倍/小于一半 → 该张不进结果 → 退回外扩 25%。实测 9 张真值平均 IoU 0.564→0.817，0 张变差。

**对账**：`tools/figsnap_eval.py --json`（Python 逐样本）+ `tools/figsnap_js_check.mjs`（JS 注入浏览器跑同批，>6px 报不一致）+ `tools/refine_js_check.mjs`；`FIG_DEFAULTS`/`DEFAULTS` 两边一字不差。

### 5.3 渲染层（三端口径）

| 端口 | 文件 | 场景 |
|---|---|---|
| 校对页 | `engine/render.py` | 本地单文件自包含 HTML（卷卡片/卷详情/单题/试卷列表） |
| 网页端 | `app/js/render.js` | 云端页面（同规则的 JS 版；**不预裁图**，按 bbox 从原图 CSS 实时抠） |
| 打印链 | `engine/paper.py` | A4 卷面 |

必须一致的三处：**符号内联 SVG**（`□○△☆■●▲★` → `.sym.*` 等宽绘制，两处 CSS 同改）、**运算符 KaTeX**（`mathify`：text 里的 `×÷+-=<>` 逐个包成 `\({}\times{})\)`，两侧空组使其成为二元算子才有正确间距；**只包运算符**，数字/方框/留空括号不动）、**插图显示外观**（`figView`/`fig_view`：`dw` 30~100 用 `--fdw` zoom、`pos` l/c/r、`wrap` 环绕；类名 `fp-*`/`fw-*`；`tools/fig_view_check.py` 21 项钉这一条）。

其他渲染规则：latex 片段直接交 KaTeX auto-render（`\(…\)`）；题干换行 → `<br>`；`[?]` 高亮；**mathify → escape → symbols 顺序不能反**（反了会把 SVG 的 `stroke-width` 连字符当运算符包掉）。KaTeX 内联包（CSS+JS+auto-render+20 个 woff2 data: URI）缓存到 `engine/vendor/katex/katex-inline.html`（源文件更新自动重建）；含公式页 ≈650KB，纯文字页 ≈160KB；`--no-katex` 可关。

### 5.4 卷面引擎（`app/js/sheet.js`）

- **照片卷（`collect`）**：按 `section` 分组（`usable()` 过滤草稿/笔迹板块与 `[?]` 题，`collect()` 与打印页共用这一判据）；列数 `inferCols`：**按照片分组**把 bbox 左边界做 gap 聚类（gap=max(40, 版面宽×15%)，孤立小簇并入最近大簇防 3 列数成 4 列），组间取 min、上限 4。
- **自建卷（`collectByType`）**：按 `bucketOf` 分 9 桶，顺序 = `TYPE_SECTION`。
- **分桶（`qtype.js`，全站唯一口径）**：`source.qtype_manual`（题库级手标）> `layout.types`（本卷覆盖）> 板块名关键词 `SEC_RULES`（顺序即优先级：判断→解决/应用→选择→**比大小**→填→竖式/递等式/口算/计算→几何→证明）> 模型 `qtype`。板块名必须压过模型题型（模型只有「解答」一档，竖式/递等式全被打成 solve）。`compare` 必须排在 `填` 之前。
- **题号方案**：`NO_STYLES`（cn/num/ABC/abc）× `NO_WRAPS`（无/、/./．/（）/()/【】/[]）；大题序号**按板块位置现算不落数据**（交换板块自动跟换）；小题号每板块从 1 起；计算题默认不印（`isCalcSec`/`smallNoFor`，板块行 `#` 可覆盖）；`normSpec` 容错（旧数据/坏值回落合法值；「没给 pre/suf」与「显式空包裹」分开判）。
- **题目渲染（`itemHtml`）**：`MARK_RE` 识别子项行（①②/（1）/1./一、）→ 子项间插答题留白；`flowText` 把多行拼回句子流（结构标记行才断行）；`optsHtml` 按 em 宽度估算排选项（汉字 1em、其他 0.55em、`A. ` 1.4em；行数定了按条数均衡分配，列宽按内容比例）；`figChoice`（带图选择题：左选项右插图，左栏宽度 = 43em − 图宽/4.233mm + 列距）；`figRight`（应用题图靠右，左边留给学生写算式）；插图宽度默认 68mm（带图选择题 62mm），排版态手柄可拖（20~170mm，双击恢复默认，拖过存 `layout.figs`）。
- **书写区**：`boxFor` 先按板块名（竖式 30/递等式 26/综合算式 12/应用 30/计算 0）再按题型兜底（solve/geometry/proof=30mm），题型缺失看题干是不是问句。

### 5.5 A4 真分页（`Sheet.paginate`）

```
flatten(host)  # 多页并回一张长卷面（同 data-si 的网格并回一个）
  → 拆块：卷头 / （板块标题 + 该板块第一行）/ 每一行题      ← 行不能跨页拆
  → 贪心装箱：页内容高 = 297 − 上边距 − 下边距 − 5(保险)，10mm 探针实测 px/mm
  → 重建：建新 .sheet，把**真实 DOM 节点**搬进去（KaTeX 不重排、图片不重请求、焦点不丢）
  → 每页右下角 .pgno「第 i/n 页」（.no-print）
```

铁律：**量高一律 `offsetTop/offsetHeight`，不用 `getBoundingClientRect`**（组卷台给卷面加了 `transform:scale`，rect 是缩放后视觉尺寸，会把页高算错——曾经因此永不换页）；跨页板块共用 `data-si`、每网格记 `data-qbase`（拖拽落点换算全局下标用）。页边距唯一口径 = `app.css :root` 的 `--pg-t/r/b/l`（预设紧凑 14/标准 18/宽松 24·22·22，存 localStorage `sj-print-margin`）；**`@page` 固定 `margin:0`**——边距交给 @page 的话，打印对话框一改「边距」就被丢掉（实测左边距 0mm）。打印侧 `.sheet + .sheet { page-break-before: always }` + `@media print` 去 padding/min-height，`@page margin:0` + 卷面内缩。

### 5.6 卷面就地排版（`app/js/sheet-edit.js`）

`SheetEd.create({host, bar, buttons, autoNo, autoSecs, alwaysEdit, canRemove, labels})`，`print.html` 与 `compose.html` 共用。状态 `LAY={qs, byId, manual, types, figw, caps, open, dirty}`；`snapshot()` 吐排版数据。两个入口的差异全在 opts：`autoSecs`（自建卷 `Sheet.collectByType` / 照片卷 `Sheet.collect`）、`autoNo:false`（照片卷标题用原卷原文、序号不自动生成、小题号不重编）。

交互：拖题（源卡片半透明、插入竖线、矩形几何落点、`gridBase(grid)+dropIndex()` 换算全局下标）、板块拖把手换序、标题就地改（**显示的就是 input 本身，改名不重画**防丢焦点）、1/2/3/4 列、`#` 小题号开关、编号面板（大题/小题各一套 spec + 实时预览串）、插图手柄（横拖改 `--figw`，`clientX` 除以缩放比、`Sheet.pxPerMm()` 量探针；拖动中只改变量不重画防重新分页换掉手柄）、图下说明开关（`layout.caps`，`figHtml()` 在 meta 判断**之前**就摘掉 `.figcap`，所以非排版态也生效）。工具条按钮 id 固定（`lay-no/lay-auto/lay-save/lay-preview/lay-done`，自检脚本按 id 找）。两条必须守住的坑：编辑态保留空板块（否则 data-si 与 manual 下标错位 → 拖错题）；关页面时 dirty 拦截。

### 5.7 云数据层（`app/js/cloud.js`）

唯一的 SDK 初始化点（`createWorkBuddyCloud({endpoint, oauthRelayBaseUrl, publishableKey})`，来自 `js/config.js` 的 publicConfig），导出 `window.CloudAPI`：

- **会话/认证**：`session/currentUser/sendPhoneCode/verifyPhone/signInWechat/handleWechatCallback/signOut/onAuthChange`。微信回调必须在任何路由守卫之前无条件调一次，并把 URL 上的 code/state 抹掉（否则刷新重放已用的 code）。
- **权限**：`ensureAccess`（无行则登记 pending，撞主键 23505 自动回读）、`listAccess`（`app_admin_users` RPC）、`setAccess`（`app_admin_set_status` RPC）。
- **业务 CRUD**：papers/files/questions/custom_papers 全套；`insertQuestions` 返回落库行（单页重扫要把新 id 接回顺序表）；`deleteQuestionsByIds` 逐条删（云端无按 jsonb 条件删除）；`setQuestionSeqs` 只写真变了的行 + 回读校验 + 偶发不生效重试一次；`pageRowsOf`（先 file 后 page）。
- **备份**：`backupQuestions`（payload=整卷快照，插完 `pruneBackups` 留 5 份）、`listBackups`（只取几列，payload 几十 KB×N 不能白传）、`restoreQuestions`（**按 seq 原地 UPDATE**，`RESTORE_NULLABLE`/`RESTORE_REQUIRED` 两列清单；只有题数变了才补/删）、`deleteBackup`。
- **存储**：`uploadPhoto`（先量 `imageSize` 再传，登记含像素宽高）、`downloadPhoto`（走 SDK `download()`，与应用同源的 `/.cloud/storage` 通道、自带鉴权，不污染 canvas）、`signedUrl`（1 小时，缓存 50 分钟；`local:` 前缀 = 随包演示图，直接当静态文件不签）。

### 5.8 本地引擎（`engine/`）

- `render.py`：四层页面。`doc_slug` = 日期 + 文件名 sha1 前 4 位（中文名直接当文件名在 URL/预览面板下出编码问题）；`paper_key = source.paper or source.file`；`paper_files` 按 `paper_page` 排序（文件名顺序与页序相反时必须标：字符串排序里 `-`(0x2D) 会跑到 `.`(0x2E) 前面）；缩略图优先 `data/thumbs/`（520px，`make_thumbs.py` 生成），缺失回退原图。
- `paper.py`：`PAPER`（基准档）/`TIGHT`（只作用于合卷）/`COMPACT`+`COMPACT_DOCS`（按卷还原的紧凑档，**逐卷点名**，不默认开）。合卷 `collect`：按 `SECTIONS.pick` 归集 + 同板块内容指纹去重（只归一空白，不动标点数字）+ `[?]` 剔除；`blanks_of` 数空（`（　　）`与`____`算空，`□`/`○`不算——它们是已知量或比较符位）；`item_score` 三口径（scores > per_blank > per）。按卷还原 `collect_doc`：`LAYOUT_RULES`（顺序即优先级，「列式计算」含「计算」必须排在前面）、`infer_cols`（按照片聚类取最小）、`--scores` 走 `SCORE_PRESET` 估计口径（stderr 明确警告）。`fix_punct` 只在打印层、只在中文旁边动手（算式里的 `.` `,` 不碰）。
- `db.py`：SQLite upsert + `--prune`。
- 版面体检 `tools/export_paper_pdf.py`：Chrome `--print-to-pdf` + PyMuPDF 逐页找**最后一个非白行**算留白（不能看 `get_text("blocks")`——空白书写区+虚线会被误报；不能看 `get_drawings()`——body 白底是整页矩形）；产物 `data/paper/manifest.json` 供 `papers.html` 读页数/PDF 体积/缩略图。

## 6. 关键流程

### 6.1 上传即识别

```
upload.html 选 N 张照片（顺序=页序）
  → createPaper(status=processing)
  → 逐张 uploadPhoto（imageSize → storage.upload → addFile 记 width/height；顺序上传，防页序乱）
  → updatePaper(page_count, status=processing, status_note="正在自动识别…")
  → location.href = paper.html?id=N&reco=1
paper.html 见到 reco=1 → 自动触发识别（照片从云端取回，无需重传）：
  → CloudAPI.downloadPhoto(每张)（SDK download()，同源 /.cloud/storage 通道、自带鉴权、不污染 canvas）
  → Recognize.recognizePaper({paperId, pages, replace:false})
      逐页：buildRulerCanvas → cloud.llm 流式 → parseJson
            → Refine.snap / snapFigures（挂了 _rb/_sb）
            → toRow → addQuestions（seq 连续）
  → updatePaper(status=done, question_count, status_note)
  → 拉 listQuestions → auditPaper → 汇总条 + 红条
```

「重新识别」按钮走同一条链路（`replace:true`，先备份、先清旧题），照片同样从云端取回——这是「重新识别免重传」的实现方式。

### 6.2 重新识别（带备份）与恢复

```
paper.html 点「重新识别」→ UI.choose（danger，逐条列后果）
  → backupQuestions（失败不阻断，但提示不可回滚）
  → recognizePaper({replace:true})：deleteQuestions → 重跑 → 插入
  → 顶部「识别备份」条 +「管理备份」弹层
恢复：restoreQuestions(backupId)：读备份 → 与当前按 seq 配对
      有的 → 原地 UPDATE（id 不变）；多出的 → 删；缺失的 → 插
```

### 6.3 组卷保存

```
compose.html 左栏点「加入」→ Sheet.buildFromManual 把新题并入同名板块（没有就新开）
  → 卷面上拖题/改标题/切列数/配编号（LAY.dirty=true，工具条亮「未保存」）
  → 「保存试卷」→ SE.snapshot() → {title, question_ids(按卷面顺序摊平), layout}
  → updateCustomPaper → history.replaceState(compose.html?id=N)，留在本页
```

### 6.4 照片卷按原卷打印

```
print.html?id=N → Sheet.collect(questions)（板块=原卷、列数=bbox 实测、题号=printed_no）
  → SheetEd.create({autoNo:false, autoSecs:Sheet.collect})「排版」按钮进编辑态
  → Sheet.paginate 真分页 → window.print（@media print 还原标题行、藏编辑件）
```

## 12. 已知问题与技术债

1. **模型坐标带随机性**：同图两次调用 y 差 10~250px；密集页上半部分可能整体漂 200~260px。已用「吸附 + 外扩兜底 + 标注」缓解，但**不是精修**；要精确坐标走本地 Python 管线（离线重算 + 按 seq 写回，不花额度不动文字）。
2. **文字错机器判不出**：漏字/认错数字/认错人名形式完全合法，自检覆盖不到——只能人工校对 + 备份兜底。
3. **建卷→上传→写库未自动化端到端验证**：RLS 要求本人登录态，脚本代不了；上线后首次真实上传即首测。
4. **「逐列行投影 + 干扰剔除」未在浏览器试过**（已排除的只是「全页统一行带 + 不剔除干扰」的朴素做法）。
5. HEIC 不支持（loadImage 报错引导转 JPG）。
6. 微信登录手机不可用（网站应用 snsapi_login 限制，产品形态所致）。
7. `figure.expr`/`geometry` 字段延后启用（图形默认走 crop）。
8. 演示模式题库只读（识别/上传不可试）。
